# আপনজন কত দূরে

ফোল্ডারের ফাইলগুলো:

- `index.html`: পেজের কাঠামো (হেডার, ট্যাব, ফর্ম, লিস্ট)
- `css/style.css`: রং, ফন্ট, লেআউট। রং বদলাতে ওপরের `:root` অংশ বদলান (ডার্ক মোডের রং তার নিচে)
- `js/app.js`: সব হিসাব আর ম্যাপ আঁকার কোড
- `js/data.js`: ৬৪ জেলার অবস্থান, জেলার সীমানা, বিশ্ব মানচিত্র আর প্রায় ৯০০ শহরের তালিকা

## চালানো
`index.html` ব্রাউজারে খুললেই চলবে। ইন্টারনেট লাগবে, কারণ ম্যাপের লাইব্রেরি (d3, topojson) আর ফন্ট CDN থেকে আসে।

## হোস্ট করা
পুরো ফোল্ডারটা যেকোনো স্ট্যাটিক হোস্টিংয়ে আপলোড করলেই হবে: cPanel এর public_html, Netlify, Vercel, GitHub Pages ইত্যাদি। কোনো সার্ভার বা ডাটাবেস লাগে না। WordPress সাইটে বসাতে চাইলে ফোল্ডারটা সাবফোল্ডার হিসেবে আপলোড করে লিংক দিন।

## সহজে যা বদলাতে পারবেন
- সাইটের নাম: `index.html` এর `<title>` আর `<h1>`
- সড়কপথের হিসাব: `js/app.js` এর `const ROAD=1.3` (সরলরেখার দূরত্বের কত গুণ)
- গাড়ি, হাঁটা আর বিমানের গড় গতি: `js/app.js` এর `DEFAULTS` অংশে `speeds`
- উদাহরণ মানুষজন: `js/app.js` এর `DEFAULTS` অংশে `people`
- সম্পর্কের তালিকা: `index.html` এর `<select id="pRel">`, আর রং ঠিক করতে `app.js` এর `FAMILY` ও `FRIEND`

## তথ্য সংরক্ষণ
ব্যবহারকারীর তথ্য তার ব্রাউজারের localStorage এ থাকে (`apon_bd`, `apon_world`)। কোথাও পাঠানো হয় না।
